01 / What I do

Move from AI experiment to product behavior.

Agent features fail when language models are treated as the whole product. I work on the surrounding system: tools, state, evaluation, observability, and the spatial domain logic that makes the agent useful.

01 / Find

Choose the job worth making agentic

Map the workflow, the users, the failure modes, and where an agent can do something that deterministic software cannot.

02 / Build

Give the agent real spatial tools

Connect GIS, point-cloud, and 3D operations so the model can inspect, transform, compare, and explain actual data.

03 / Ship

Engineer beyond the happy path

Add evaluation, tracing, recovery, and human checkpoints so a promising prototype can become dependable product behavior.
