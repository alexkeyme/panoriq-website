# panoriq visual identity

This folder contains the current panoriq visual identity.

## Active files

- `fonts/Manrope/` - primary typeface and logo export source
- `fonts/Fraunces/` - editorial accent typeface
- `logo/svg/` - master contour-q vectors
- `logo/mark-light/` and `logo/mark-dark/` - raster mark exports
- `logo/favicon/` - simplified favicon exports
- `logo/lockup/` - mark and Manrope wordmark exports
- `logo/linkedin/banner-linkedin.svg` - current LinkedIn banner
- `logo/generate.py` - deterministic logo export script
- `logo/index.html` - export overview
- `panoriq-brand-system-v2.html` - current brand guide

The website directly references only selected favicon, mark, SVG, and lockup files. The remaining active exports are kept for social media, presentations, print, and future application icons.

Superseded explorations and exports are stored in `legacy/` and are not used by the website.
